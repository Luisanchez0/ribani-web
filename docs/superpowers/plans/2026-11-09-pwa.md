# PWA de RIBANI

> **For agentic workers:** usar `superpowers:executing-plans` para ejecutar y verificar estas tareas en la sesión actual.

**Goal:** RIBANI instalable, caché de archivos estáticos y aviso de desconexión.

**Architecture:** `vite-plugin-pwa` genera el manifiesto y un service worker con precaché de archivos locales. La navegación SPA puede abrir desde caché; las llamadas HTTP, SSE y los mapas no se almacenan en Cache Storage. Un aviso global observa los eventos de conexión del navegador sin cambiar autenticación ni estado de servidor.

**Tech Stack:** React 19, Vite 8, TypeScript strict, Tailwind, vite-plugin-pwa 2.

**Spec:** alcance elegido por el usuario en la conversación: «por ahora pwa instalable, cache de archivos estaticos y aviso de desconexion».

## Restricciones

- Sin cambios en backend, API generada, permisos o sesión.
- Identidad RIBANI y escudo existente; iconos PNG normales, adaptativo y Apple.
- Solo precaché estática; sin caché de API, mapas, tokens o datos personales.
- El aviso aparece en login, restauración de sesión y rutas protegidas.
- HTTPS en producción; localhost para verificar el build.
- El estado del navegador indica conexión de red, no disponibilidad del backend.

## Foco de revisión

- Recargar una ruta profunda sin conexión después de una primera visita online.
- No almacenar respuestas HTTP/SSE ni documentos que no sean la SPA.
- Mantener visible el aviso en móvil sin tapar controles.
- Publicar el service worker y manifiesto sin caché HTTP prolongada.
- Respetar la limpieza de sesión existente; abrir offline no permite autenticarse.

## Validación

El aviso y la configuración son cambios pequeños y reversibles: no agregar pruebas unitarias que dupliquen la implementación. Se ejecutaron 51 pruebas existentes, TypeScript, ESLint y build. Dev y preview responden HTTP 200; preview entrega el manifiesto con `application/manifest+json`.

Una comprobación temporal en Node ejecutó el service worker generado y el runtime real de Workbox contra Cache Storage y red simuladas: siete navegaciones offline devuelven la SPA sin llamadas de red; seis rutas de navegación ajenas y tres peticiones HTTP/SSE no se interceptan; diez archivos estáticos en caché. Las dimensiones PNG corresponden al manifiesto. Esta comprobación no sustituye al navegador.

La revisión independiente no encontró hallazgos accionables. La herramienta CUA detuvo la prueba visual porque no pudo determinar la URL de Edge con suficiente certeza; su host de browser tampoco estaba disponible. No se comprobó instalación real ni emulación móvil.

`npm audit` reporta 18 avisos: 2 bajos, 13 moderados y 3 altos. Los paquetes con avisos altos (`vite` 8.3.2, `follow-redirects` 1.16.1 y `zod` 4.6.5) conservan las versiones que ya estaban en HEAD. La cadena nueva de Workbox incorpora avisos bajos/moderados de herramientas de build; la reparación automática propuesta degrada el plugin a una versión mayor anterior. La revisión de dependencias queda fuera de este cambio; no se aplicaron degradaciones ni actualizaciones ajenas a la PWA.
